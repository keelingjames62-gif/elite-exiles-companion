# Changelog

## 1.8.0

- Changed the plugin to local-first operation.
- Coach Integration is now disabled by default.
- Added a RuneLite configuration warning to the opt-in Coach Integration toggle describing the third-party connection and data sent.
- Added defense-in-depth network guards so Elite Exiles requests cannot be created while Coach Integration is disabled.
- Live session sync is now disabled by default.
- Added a useful local dashboard with total level, session XP, XP/hour, skill count, and core levels.
- Hid Coach action controls while Local Mode is active.
- Kept the larger, higher-contrast sidebar text from v1.7.
- Chat features remain removed.
